# muzak-rs

This is a library and command-line suite for the creation of inauthentic chiptune-style music.

For more information, see [muzak-web's writeup](https://pub.colonq.computer/~the0x539/bells/), or for further historical context, [Bezelea's original page](https://pub.colonq.computer/~bezelea/bells/).
